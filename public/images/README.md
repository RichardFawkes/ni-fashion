# Imagens para o Catálogo Ni Fashion

Esta pasta contém as imagens utilizadas no catálogo digital da Ni Fashion.

## Padrão de Nomenclatura

As imagens devem seguir este padrão de nomenclatura:

- `cropped1.jpg`, `cropped2.jpg`, etc. - Para imagens de cropped
- `dress1.jpg`, `dress2.jpg`, etc. - Para imagens de vestidos
- `blazer1.jpg`, `blazer2.jpg`, etc. - Para imagens de blazers
- `pants1.jpg`, `pants2.jpg`, etc. - Para imagens de calças
- `skirt1.jpg`, `skirt2.jpg`, etc. - Para imagens de saias
- `set1.jpg`, `set2.jpg`, etc. - Para imagens de conjuntos
- `jacket1.jpg`, `jacket2.jpg`, etc. - Para imagens de jaquetas

## Dimensões Recomendadas

Para melhor exibição no catálogo, recomendamos:

- Proporção 4:5 (por exemplo: 800x1000 pixels)
- Resolução mínima de 800x1000 pixels
- Formato JPG ou PNG
- Tamanho máximo de arquivo: 500KB

## Como Gerar Imagens Temporárias

Se você ainda não tem imagens para o catálogo, pode usar a ferramenta de geração de imagens incluída neste projeto:

1. Acesse a página `/image-generator` no site
2. Selecione a categoria desejada
3. Clique em "Exportar Todas as Imagens"
4. Salve as imagens geradas nesta pasta usando o nome de arquivo indicado

## Nota sobre Uso de Imagens

Certifique-se de ter direitos de uso das imagens que incluir no catálogo. Para um site de produção, recomendamos:

- Usar fotos profissionais dos seus produtos
- Manter um padrão visual consistente
- Destacar os detalhes das peças
- Mostrar as peças com e sem modelo, quando possível
